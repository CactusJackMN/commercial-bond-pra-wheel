# Commercial Bond PRA Wheel

Interactive wagon-wheel map of **28 commercial-surety surveillance factors** (3 Cs-plus: Character, Capacity, Capital, Collateral, Conditions).

## Open the model

- Download [`index.html`](./index.html) and open it in Chrome, Edge, or Firefox.
- GitHub’s file preview does not run the GUI — use **Download raw file**, then open locally.

## How to use

1. Name the hub (principal or bond).
2. Set each factor 1–10. Spoke color and thickness follow residual risk.
3. Click a node to open that factor’s PRA tree and source list.
4. **Download JSON** saves current scores.

20 factors are general (principal / market). 8 are instrument-specific (this bond, license, collateral, or indemnity).
